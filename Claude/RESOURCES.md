All DVDs and Specs Google Sheet:
This is a google sheet that holds all the information regarding the titles. the rows in the spreadsheet are as follows: Title (Name of the movie/tv), Movie or TV (Options: Movie, Short, Video, Documentary, TV Series, TV Mini-Series, TV Special etc.), Season No. (If the title is a TV Series or TV Mini Series etc. it's season number is listed here. Movies will leave this entry as n/a [numerical values only{Except for special exclusion case listed later}]), Part of a Season no. (if the title is a TV Series/TV Mini Series etc. and is only part of a series rather than the full series, that part number is listed here. Movies will leave this entry as n/a. [numerical values only]), Episode Count (lists the number of episodes that are on the disks of the title, not the amount of episodes in the season, but the number on the disk. This is to prevent confusion with some disks being part of a series or having episodes from multiple seasons etc. If there is a case where there are episodes from multiple seasons in a title like for example a cartoon collection, then the Season no. will be set to 'various'. Movies will leave this entry as n/a. [numerical values only for episode count]), Release Date (date of the original release of the title. On obscure titles that only have a year as their release date, the release date will be set to 1/1/(year). Date format is set as dd/mm/yyyy[numerical and / only (numbered date format]), Running time (running time of the title in minutes. Be mindful that different cuts will have different runtimes. TV Seasons will not be given runtime data and leave the entry as n/a[format (number)mins]), Genre (the genre of the title, many genres can be listed separated by commas), Director (the director of the title, or directors (separated by commas)), Franchise (If the movie is part of a franchise like star wars, marvel, dc, universal monsters, or has any sequels or prequels it will be listed in this entry, if not it will be left as n/a), Sub-franchise (used if there is a cross over or subcategory in franchise, for example the MCU containing Iron Man movies, X-Men containing Wolverine movies, or Universal Monsters containing Frankenstein Movies. If there is no subcategory, it will be left as n/a), Rating (Maturity/content advisory rating of the movie [G, PG, M, R16 etc.] Ratings will be based on what the case of the title says, but if that information is unavailable go by the NZ Rating), Format (Format of the title [DVD, CD, Blu-Ray, 4K UHD Blu-Ray, Blu-Ray 3D, DVD Steelbook etc.], if a title has two formats in it, then the highest quality format is prioritized.), Disc Count (Total number of disks in title, [numerical only] if title is a title in a collection, then the number of disks that relate to that specific title are counted instead of the total number of disks in the collection), Special Features (notes if the title has special features or not [Boolean: 'yes' or 'no'], if the title is a title in a collection then if that title has specific special features for that disk then it is denoted as 'yes', special features that belong to a dedicated special features disk or special features that exist on another title do not count), Special Features Disk Count (if the title has a dedicated disk for special features [numerical only], if the title is a title in a collection, the dedicated disk only counts if it is specifically dedicated to that title, if it is a special features disk for the entire collection then it is not), Special Features Disk Format (if the title has a special Features disk, this field will denote the format [DVD, Blu-Ray, 4k UHD Blu-Ray etc.]), Animation or live action (notes if the title is in animation or live action, if the title is animated, it will note what type of animation it is: 2D animation, 3D Animation, Claymation, Stop motion etc.), Documentary (notes if the title is a documentary or not. [pseudo Boolean 'y' or 'n' or Other] if the title is not a documentary it will be given the value of n, if it is specifically a documentary it will be given the value of y, however if it is mostly true but not specifically a documentary, it may be given a value depending on it's realism. For example, it if it is a biopic, the value is biopic, or if it's based on a true story it the value would be 'based on a true story' etc.), Collection (Mentioned in definitions.md but as a recap a collection is when multiple titles whether that be movies, tv seasons etc. exist in a single title known as a box set. If this is the case then it is noted in this entry [Boolean 'y' or 'n']), Name of collection (the name of the collection, if this is the entry for the collection itself, then the collection name would be the title, if it is one of the subsequent entries for a title in a collection then the collection name would be same as the title that it is part of the collection of), Title in a collection (notes if the entry is a title in a collection. [Boolean 'y' or 'n'] If an entry is a title in a collection then the collection value must be 'n', if the entry is a collection then the title in a collection vaule must be 'n'), Number of titles in a collection (Notes the number of titles in the collection, if the title is a collection or the title is a title in a collection then they both must inlcude the total number of titles in thier collection and for a title in a collection the number is inclusive of their own title [numerical only]), Rotten Tomatoes Page (link to the title's rotten tomatoes page, does not apply to collections or titles that don't have a rotten tomatoes socre), IMDB page ( link to the titles imdb page, does not apply to collections, all titles should have an imdb page), Studio (Lists the primary studio that made the film), Disk region (lists the region of the disk, all disks in a collection should have the same region. DVD regions span from 1 to 4, Blu-Ray Regions span from A to C, and 4K UHD disks are region free.). If a column can not be filled out due to not being a collection or not having special features etc. it will be left as n/a. I would recomend giving the entire sheet a look through to see what the format and the data patterns are so you can better understand how to intrepet it for future scraping and writing algorythms.

IMDB/OMDB:
IMDB is biggest movie database on the internet and should contain all the possible details that the program might need about a movie (but not necessarily about it's physical media release) this information would be most important for web app specifically given the design that I plan to implement for it. However one of the drawbacks of IMDB is that it does not have a public API so it can't be scraped as easily. OMDB is a very similar Database to IMDB except for it doesn't quite have as much information, but it does have a public API which should make it easier to wield for this application. I would prioritize OMDB first due to ease, however if the details are not available there, I would instead grab the information from IMDB.
IMDB link
https://www.imdb.com
OMDB Link
https://www.omdb.org/en/us/
Blu-Ray.com:
Blu-Ray.com is the largest online database to do with physical media and has information about almost every Blu-ray release (but I'm not sure if they have information on DVD releases or other physical media formats). If there is information missing to identify the title based on the barcode, Blu-Ray.com be used as guide to try and find a release that matches or if there is no match, find information on a release that is very similar.
