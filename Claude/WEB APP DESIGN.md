**WEB APP DESIGN**

OVERVIEW:

The web app will act like a mix of the GUI of Netflix and IMDB. The browse page will look like Netflix, but once you click on a title, beucase functionally you can't play a title directly from the web app, it will show a page similar to an imdb page with movie data and data about the specific physical attirubtes of the title: disc count, format, what region it is etc. there will be a search bar up the top where you can search by movie, collection, tv, actor, franchise, director etc. The mobile version will have the scanner directly built into the web app



HOME/BROWSE PAGE:

The Home/browse page will feature a header up the top that will contain the logo in the top left hand corner (I have no idea what the logo design will look like but for now just include the text 'DANFLIX 5.0' in blue), in the middle of the header will be the search bar, and the right side of the header will have settings (In the settings there will be a single option to open the portal for direct database access but no other settings for now, in future updates I might add settings. In the mobile version of the app there will be a fourth element that sits between the logo and the search bar that will open up the scanner feature. The main body of the home/browse page will look similar in design to Netflix with rows of scrolling posters with headers above each row that tell what the row is. Some of the rows for titles could include: Recently added, New releases this year, classics, (specific Franchise), (specific Genre), (specific DVD Collection Set \[shows titles in the collection in the list rather than the collection set itself]), weird and wonderful, etc. similar to Netflix it could have an 'infinitely scrolling vertical axis' so the user never reaches the end of rows, but each row should terminate at an end and not scroll forever, because I quite dislike that about Netflix, especially when they do that for franchises and you see the same titles over and over.

Design: Dark Gradient Design, Rigid non rounded icons, triangles, Light Blue Accents.



ADVANCED SEARCH FEATURES:

Basic Search:

When typing into the search bar it will show the titles that are closest to what the user has put in. The entries will appear showing their name, date, and poster/image of DVD set. The movies/TV Themselves and the physical media that they belong to will have different entries. For example if a user types Vertigo into the search Vertigo will appear as an option as well as Vertigo (Blu-Ray), Vertigo (4k UHD Blu-Ray), and Alfred Hitchcock 4 Film Masterpieces Collection (4k UHD Collection), Alfred Hitchcock, along with any other title that has the word vertigo in it. The first result will be the general result for vertigo, similar to an IMDB page, and will include somewhere on that page a list of the other titles that are related to Alfred Hitchcock's vertigo, but not any other vertigo. The titles in that list will also act as links to those pages. The second and third result would show the physical version of that movie with all of the physical details like disk count, special features, etc and will have a link to the first entry with imdb-like page. The fourth entry the collection, would show the details about the collection how many disks it and the details of that collection specifically as well as a list of all titles on that collection. The titles in that list will also act as links to those pages. The Alfred Hitchcock Entry will act like a bio page for a director on IMDB and will list all the titles that the database holds of that director's movies. The titles in this list will also act as links to those pages. There will be similar page to this that will exist for movie franchises or actors.

Advanced Search:

When opening the search bar there will be an option to add filters to find specific entries or block other entries from showing. as well as a sort by option that will sort titles by various criteria. The search filters that users can add include but are not limited to: Movie or TV, Release year (or/and month), Runtime, Genre, Franchise, Rating, Format, Animation/Live Action, Documentary/Realism level (biopic, doco, based on true events), Is a collection, is a title in a collection, Rotten tomatoes Score, IMDB Score, Rotten Tomatoes Audience Score, Letterboxd Score, Metacritic Score, Studio, Disk Region, taste profile, Director only, Franchise only, Physical titles only, Actors only, is a steelbook, and probably more which I might discover I need in the future. Multiple filters can be added at the same time. Some of these filters can be implemented within ranges using a slider, for example for the year filter you can select a release date range like from 1940 to 1960 or a rotten tomatoes critics score between 70% to 90%. Movies can also be sorted by multiple metrics including: alphabetical, release date popularity (measured through imdb ratings traffic and other movie database platforms), Runtime, and probably other metrics that I am yet to think of. Within the filter settings there should be some option to create taste profiles. When the user creates a taste profile they can set a name to it, and from there they can go through all the filters and select what suits that users taste and then save it, much like a filter preset. Then in future if a few of these taste profiles are set up, a user an input a few of these profiles into the filters and the search will return movies that would have been included in both profiles. to find an average middle ground of titles that both people would enjoy.



TITLE PAGES:

The title page refers to the page that will appear when a user clicks on any of the posters on the homepage/browse page or any of the entries that appear in the search function. Upon click the user will be taken to the title page for that particular movie/tv/DVD/Blu-Ray. There are 4 different types of title pages, these are Movie/TV Pages, DVD Pages, DVD Collection Pages, and Cast/Crew/Franchise Pages. All entries will have a header at the top of the page below the home page header which exists on all pages, this new header shows the title of the movie and a back button which takes the user back to the previous page that they were on. This is because on each title page there are different links that lead to other title pages so if a person is investigating it is helpful that the back arrow goes to the previous page rather than all the way back to the home or search page. 

Movie/TV Page:

The Movie/TV Pages will act like an IMDB entry. They will start with the title of the movie, runtime, year of release, and imdb, rotten tomatoes and letterboxd scores which will sit parallel to the movie poster. Below this will be the synopsis of the movie. If it is a TV series the synopsis is then followed by a burnt in Series browser where a user can select Series and see what episodes are in each series. The number of series are dependent on what series exist in my collection. After the series browser/synopsis there is a horizonal scrolling list that shows how many items in my collection contain this movie, each of the items on the list is a link that sends the user to that specific DVD page/DVD collection page. Following that there is a circular image that show the director with the director's name underneath that would take the user to the page of that director, underneath that is a scrolling horizontal list for the cast with circular images for each of the people with their name and the name of their character underneath, if clicked on it would take the user to the page of each of those members of the cast. Below that there would be a scrolling crew list that has a circular image for each of the crew with their name and role underneath. I might in future decide to have another few pieces of information underneath this part of the page but I can't think of what to add for now. just be aware that it could expand in future.

DVD Pages:

These pages are representative of each of the titles in my entire collection. For example, I might have one Film/TV Entry for 1931's Dracula, but I would have two DVD pages for it, one for the DVD I own, and one for the title that exists in a Universal Monsters Blu-Ray Collection that I own.

&#x20;These pages will have the following Information on them. They will first start with title of the movie, then note the format (DVD, Blu-ray), and the amount of disks it has, disk region and if it has special features. Ajacent to this information will be the image of the collection. Below both that informaiton and the poster, there will a brief description of the specific physical media release if there is any information about it. Below that would be a list that has links to it's respective Film/TV entry, Franchise Entry (if it has one) or collection that it is a title of (if it is part of a collection)

DVD Collection pages:

DVD Collection pages are very similar to DVD Pages except for they only include information about the collection as a whole. so would include all the disks in the collection rather than just the disks counted for a specific title for example. they will also follow with an image, description and list. But the list will list all the DVD pages for each of the respective titles in the collection as well as the movie and TV pages for those titles as well as the Franchise page (if is related to a franchise/actor/director)

Cast/Crew/Franchise Pages:

These pages will start with the name of the franchise/person and follow with a circular image that will sit beside the image, below that there would be a brief description about the franchise, or a brief biography about the person. Followed by a list of all the pages that the person/franchise is connected to. Because one of these pages can be involved with so many other pages. the movie and TV pages and the DVD/ DVD collection pages are separated by tabs, perhaps there could even be a mini search bar for each tab (with no advanced search features) if the number of items in the list is above 20. Each of the items in the list link to their respective pages of course.

Design: Dark Gradient Design, Rigid non rounded icons, triangles, Light Blue Accents, Blurred darkened zoomed in version of poster in background.

DIRECT DATABASE ACCESS:

In the settings found on the homepage, as mentioned previously, this will be the only entry in the settings for now. The setting will be titled 'Direct database Access' When clicked on it will navigate to some page with a UI where a user can interact with the database, any changes on this database will automatically update the google sheets as well. Specifically this feature is implemented in case something goes wrong with the data processing or some titles and categories are shifted about. For example, when my DVD collection expands, some of the genre categories get to large, and occasionally I break them up into finer categories, like for example breaking up drama into drama and teen drama, or breaking up fantasy into fantasy and sword and sorcery. If I were to enact these changes on my physically collection and have no easy way to directly update the database from this feature, the film location notification that pops up after a scanning a disk could become inaccurate for some genres. At the top of the database entries there could be a search bar for each column as well as a global search bar for the entire database, that way I can find titles quickly. The search could also have filters that could be selected to narrow down search for example to just blu ray etc. Once I have found a title I want to change, I would just click on the cell and change the data for that entry. If I wanted to change the data of multiple cells at the same time, I could search and select a cell and it would stay at the top of search for easy access, so once I have selected all the titles from the search, I can then click on the cell of one of the selected entries and replace the data and the data in the columns of all the selected entries will change to the value that I had given the first one for bulk modification. There are probably other features that I could implement with this, but I am not sure what else to add.
